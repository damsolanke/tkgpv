# TKG-PV

A bitemporal, evidence-aware ontology for temporal reasoning in pharmacovigilance knowledge graphs, by Dam Solanke. It was written for Phase 1 of the NIH challenge "It's About Time: Temporal Reasoning in Biomedical Knowledge Graphs".

The ontology (OWL 2 DL, Turtle) and its documentation will be published in this repository after Phase 1 closes on 15 January 2027, under CC BY 4.0.

Persistent identifier: https://w3id.org/tkgpv (terms use the namespace `https://w3id.org/tkgpv#`).
